# LLM operator contract

The single researcher is the primary music interface. It chooses bounded evidence tools according to the task, answers directly when possible and stops unproductive exploration. Existing graph results render with their real identities while research continues. No mandatory graph creation, background model review or fake preview-save state exists.

A graph update is a retrieved view or a confirmed write; these meanings stay distinct. New evidence and preferences use typed classes and explicit transaction receipts. Source documents are untrusted data. Album scope, track exceptions and imported identities must be preserved. Private listening records stay out of public graph browsing. Nick/Guest attribution is a development convenience.

User decisions use a modal with Approve, Deny and Defer. Ordinary read research needs no approval. Approved actions bind to their stored payload/version, reject stale preconditions and apply idempotently. Deferral preserves the decision for the run's 24-hour lifetime. User feedback about liking a song is separate from a scrobble or an acoustic similarity score.
